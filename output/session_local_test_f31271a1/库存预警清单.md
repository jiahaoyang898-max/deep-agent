# 🚨 沃华医药库存预警清单

**报告日期：** 2024年  
**报告编号：** INV-WARN-2024-001  
**编制部门：** 仓储物流部  
**数据来源：** 企业ERP数据库（实时查询）

---

## 一、概述

为确保公司药品供应稳定，保障临床用药需求，沃华医药定期对库存储备情况进行监控与分析。本库存预警清单基于ERP系统实时库存数据，筛选出当前库存数量最低的10种药品，旨在提醒采购及仓储管理人员重点关注低库存药品的补货与调配工作，避免因库存不足而影响销售和客户交付。

本次预警清单覆盖品种包括心血管类药物、降糖药物、抗生素类、解热镇痛类等常用药品品类，需引起高度重视。

## 三、重点品种详细说明

### 3.1 🔴 严重偏低级别（库存＜10,000）

#### （1）阿托伐他汀钙片（20mg×7片）— 库存7,500
- **用途说明：** 主要用于治疗高胆固醇血症和冠心病的预防，属于他汀类降脂药物。
- **风险警示：** 该品种库存仅7,500个单位，为全部监测品种中最低水平。考虑到该类慢性病用药的日常出货量较大，建议立即启动紧急采购程序，并联系供应商确认最快到货周期。
- **建议措施：** 向采购部门提交加急采购申请，同时评估是否需要从其他仓库调拨支援。

#### （2）硝苯地平控释片（30mg×30片）— 库存9,500
- **用途说明：** 钙通道阻滞剂，用于治疗高血压和心绞痛，是常用的降压药物。
- **风险警示：** 库存量9,500处于极低水平。高血压患者需长期规律服药，断供风险较高。
- **建议措施：** 优先安排补货订单，并与至少两家供应商保持供货关系以确保供应链安全。

#### （3）注射用头孢曲松钠（1.0g/支）— 库存10,500
- **用途说明：** 第三代头孢菌素类广谱抗生素，用于多种细菌感染的治疗，常用于临床输液场景。
- **风险警示：** 作为医院常用注射类抗生素，需求量大且紧急程度高。库存不足可能直接影响临床治疗。
- **建议措施：** 立即与生产企业和经销商沟通订货事宜，必要时启用战略储备库存。

### 3.2 🟡 偏平级别（10,000≤库存＜15,000）

#### （4）盐酸二甲双胍片（0.5g×48片）— 库存13,500
- **用途说明：** 一线口服降糖药物，广泛用于2型糖尿病的基础治疗。
- **建议措施：** 尽快下单补货，维持安全库存水位。

#### （5）阿司匹林肠溶片（100mg×30片）— 库存13,500
- **用途说明：** 抗血小板聚集药物，用于心脑血管事件的二级预防。
- **建议措施：** 同步启动常规采购流程，确保下月出库需求得到满足。

### 3.3 🟠 关注级别（15,000≤库存＜30,000）

#### （6）蒙脱石散 — 库存24,000；（7）阿莫西林胶囊 — 库存25,000；（8）磷酸奥司他韦胶囊 — 库存25,500
- **建议措施：** 上述品种库存处于中等偏低水平。其中磷酸奥司他韦胶囊在流感季节需求量可能大幅上升，需提前储备充足库存。建议在月度计划中加入补货项。

### 3.4 🟢 正常偏低级别（≥30,000）

#### （9）布洛芬缓释胶囊 — 库存47,000；（10）连花清瘟胶囊 — 库存160,000
- **说明：** 这两个品种库存相对较为充足，但布洛芬缓释胶囊接近常规警戒线，也应在近期采购计划中予以考虑。

## 五、处置建议

1. **紧急采购：** 对"严重偏低"级别的3个品种（阿托伐他汀钙片、硝苯地平控释片、注射用头孢曲松钠），请采购部门立即启动加急采购流程，力争在3个工作日内完成订单下达。

2. **安全库存复核：** 建议仓储部门重新评估上述10个品种的最低安全库存水位，结合历史销售数据和季节性因素，制定科学的安全库存标准。

3. **供应链多元化：** 对于关键短缺品种，应拓展备选供应商渠道，降低单一来源带来的断供风险。

4. **跨仓调拨：** 若公司存在多个仓储中心，建议核查其他仓库的同品种库存情况，通过内部调拨快速平衡各仓库存。

5. **动态跟踪：** 将该清单中的品种列为每日动态监控对象，每日更新库存变化状态，确保及时发现异常波动。

6. **销售端协调：** 与销售部门沟通协调，对于低库存品种做好客户预期管理，避免超卖导致的违约风险。
